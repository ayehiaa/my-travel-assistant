# Implementation Plan: Monthly Expense Category Chart

**Branch**: `002-expense-category-chart` | **Date**: 2026-05-20 | **Spec**: [spec.md](./spec.md)

## Summary

Add a stacked bar chart to the Expenses page that shows total spend per expense category per calendar month. The chart is rendered client-side inside the existing `ExpenseList` component using data already loaded on the page. Recharts is introduced as the only new dependency. A new pure aggregation function computes the chart data and is covered by unit tests.

**Performance Goals**: Chart renders synchronously from already-loaded data; no perceptible delay

**Constraints**: No new API routes. No new DB columns. Chart must work at 375px viewport width.

**Scale/Scope**: Single chart component added to one existing page

## Implementation Details

### 1. `src/lib/expenseChartData.ts`

Export:
```ts
export const CATEGORY_COLORS: string[] // 12-color palette
export function buildExpenseCategoryChartData(
  expenses: ExpenseWithCategory[],
  categories: ExpenseCategory[],
  currency?: string  // defaults to 'GBP'
): BuildExpenseCategoryChartDataResult
```

Logic:
1. Filter `expenses` to `currency` (default 'GBP'). Set `hasMultiCurrency = true` if other currencies exist.
2. Sort `categories` by `display_order`. Assign `categoryColors[cat.id] = CATEGORY_COLORS[i % 12]`.
3. Group filtered expenses by `expense_date.slice(0, 7)` (YYYY-MM). Collect unique months, sort chronologically.
4. For each month, build a `ChartRow`: `{ month, label, [cat.id]: sumAmount }`. Categories with no expense in a month get `0`.
5. Return `{ rows, categoryColors, hasMultiCurrency }`.

### 2. `src/lib/expenseChartData.test.ts`

Test cases:
- Empty expenses → `rows` is empty, `hasMultiCurrency` false
- Single month, single category → one row, correct amount
- Multiple months, multiple categories → correct row count, correct amounts, sorted chronologically
- Multi-currency expenses → `hasMultiCurrency` true, only GBP amounts appear in rows
- Category with no expenses in a month → amount is `0` for that slot
- Category color assignment → first category gets `CATEGORY_COLORS[0]`, second gets `CATEGORY_COLORS[1]`

### 3. `src/components/expenses/ExpenseCategoryChart.tsx`

`'use client'` component.

Props:
```ts
interface Props {
  expenses: ExpenseWithCategory[]
  categories: ExpenseCategory[]
}
```

Renders:
- If no GBP expenses → empty state: `<p>No expenses to display yet</p>` (or matching currency)
- Otherwise: Recharts `<ResponsiveContainer width="100%" height={280}>` wrapping `<BarChart>` with `<Bar>` per category (stackId="a"), `<XAxis dataKey="label">`, `<YAxis tickFormatter>`, `<Tooltip>`, `<Legend>`
- Multi-currency note: small `<p>` below chart if `hasMultiCurrency`
- Y-axis formatter: values ≥1000 display as `£1.2k`; exact below 1000

### 4. `src/components/expenses/ExpenseList.tsx`

Add to the top of the JSX return (before the near-limit banner):
```tsx
<ExpenseCategoryChart expenses={expenses} categories={categories} />
```

No other changes. `expenses` (unfiltered) and `categories` are already in scope.
